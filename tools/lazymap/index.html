Lazymap

A single command for network penetration testing. It chains selected Nmap NSE scripts, sslscan, ssh-audit, dig, ldapsearch, curl, rpcclient, selected Metasploit modules, PRET and wget against one host or a list of them.

How to run it

Make it executable with chmod +x lazymap.sh, then run ./lazymap.sh -u host for a single target or ./lazymap.sh -t hosts for a file of them.

Needs Bash 5.2 or newer. Run under sudo for the UDP scan, since the Nmap scripts behind it require raw sockets.

Only point it at hosts you are authorised to test. It is noisy by design and makes no attempt to be subtle.

Options

Flag What it does
-uScan a single host.
-tScan every host in a file.
-1Add the vulners NSE script.
-2Add the vuln NSE script.
-3Add both. Slow across many targets.
-4Firewall evasion scan.
-aSkip the all-ports and UDP scans.
-nAdd -n -T4 for a faster run.
-kSkip sslscan, ssh-audit and the header check.
-bAdd -A --min-rate 1000 --open for speed and open ports only.
--pretPrinter security check via PRET (credit: Jens Mueller).
-hShow the help text.

Flags combine, so a full run reads like ./lazymap.sh -t hosts -12bank --pret.
