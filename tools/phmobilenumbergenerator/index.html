Run

1

Save the script

Download it above, or copy it out of the viewer.

cd ~/Downloads
2

Set how many you want

Optional. Edit num_numbers near the top — it defaults to 1000.

num_numbers = 5000
3

Run it

It finishes instantly and writes the file beside itself.

python3 phmobilenumbergenerator.py
4

Collect the output

One number per line, ready to paste into a form or load as a dataset.

head philippine_mobile_numbers.txt

What it produces

A plain text file, philippine_mobile_numbers.txt, with one 10-digit number per line. Each is a three-digit network prefix followed by seven random digits, so every line starts with a 9 and looks like a real local-format mobile number.

The numbers are random, not checked against any registry, and not verified as unassigned. Treat them as filler for forms and datasets during Vulnerability Assessment and Penetration Testing — never as a list to actually contact.
